# 메이플 플래닛 유틸리티 플랫폼 요구사항 명세서

### 1. 프로젝트 개요

| 항목 | 내용 |
| --- | --- |
| **프로젝트명** | 메이플 플래닛 유틸리티 (가칭) |
| **목표** | 유저의 현재 상태(스탯)를 기반으로 템셋팅의 시행착오를 없애주는 **데이터 기반 정밀 스펙업 플랫폼** |
| **핵심 타겟** | 깡스탯과 퍼센트(%) 사이에서 최고 효율의 장비를 고민하는 중·고자본 유저 및 사냥터 진입을 준비하는 유저 |
| **기술 스택** | Spring Boot (백엔드) / React (프론트엔드) / MySQL (DB) / AWS + Docker (인프라) |

---

### 2. 기능 요구사항

### 2-1. [V1.0 MVP] 아이템 정밀 비교기 (스공 계산기)

| ID | 요구사항 | 우선순위 |
| --- | --- | --- |
| **REQ-01** | **유저 스탯 입력:** 직업, 레벨, 순수 주/부스탯, 기존 장비 스탯/퍼센트/공마 합산을 입력받는 폼을 제공한다. | High |
| **REQ-02** | **비교 아이템 입력:** 유저가 비교하고자 하는 대상 아이템 A와 B의 스탯 정보를 입력할 수 있다. | High |
| **REQ-03** | **스공 계산 백엔드 로직:** 직업별 무기 상수와 주/부스탯 가중치를 적용하여 '최종 스탯 공격력(스공)'을 도출하는 알고리즘을 구현한다. | High |
| **REQ-04** | **결과 반환 API:** A 착용 시 스공, B 착용 시 스공, 그리고 두 아이템 간의 **최종 스공 차이값**을 계산하여 반환한다. | High |

### 2-2. [V2.0] 사냥터 n방컷 계산기 (확장 기능)

| ID | 요구사항 | 우선순위 |
| --- | --- | --- |
| **REQ-05** | **n방컷 로직 적용:** V1.0에서 도출된 유저의 스공 데이터를 기반으로, 특정 몬스터를 스킬로 타격했을 때의 타수(n방컷)를 계산한다. | Mid |
| **REQ-06** | **스킬 및 몬스터 데이터 연동:** 직업별 주력 스킬 퍼뎀과 몬스터의 방어력/속성/체력 데이터를 계산식에 반영한다. | Mid |

### 5. 로드맵 및 MVP 범위 한계선 (Scope)

- **V1.0 (현재 MVP 집중 목표):** 단순한 스탯 치환(환산)이 아닌, **'유저의 현재 캐릭터 상태'를 기준으로 두 아이템의 스공 차이를 정확하게 보여주는 백엔드 API와 UI 연동**까지만 완벽하게 구현하여 런칭.
- **V2.0 (트래픽 견인):** V1.0의 로직을 재사용하여 사냥터 몬스터별 n방컷 데이터 제공.
- **V3.0+ (도파민 유도):** 서비스 안정화 및 유저 확보 후 큐브, 혼줌 등 확률 기반 콘텐츠 순차적 업데이트.
