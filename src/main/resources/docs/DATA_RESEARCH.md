## 가설 채택 공식 (V1.0 구현용)

```
최대 스공 = (주스탯 × 무기상수 + 부스탯) × 총공격력 / 100
```

> 메이플 플래닛 운영진이 수치를 임의 수정했을 가능성 있음. 인게임 실측으로 검증 필요.

## 스탯% 적용 범위 (커뮤니티 검증)

% 스탯은 순스탯(직접 찍은 값)에만 적용되는 것이 아니라 **장비 깡스탯 포함 전체에 곱연산** 적용됨.

```
최종 주스탯 = (순스탯 + 장비 깡스탯 합) × (1 + 스탯% / 100)
```

**% vs 깡스탯 교차점 공식** (15% + 깡N vs 18% 비교 예시):
```
0.15 × (x + N) + N < 0.18 × x
→ x > N × (1 + 0.15) / 0.03 = N × 38.33...
→ 총 깡스탯이 N × 38 이상일 때 18%가 유리
```

실측 결론 (도적 기준):
- 120제 깡스탯 14: 537 이상 (약 108레벨) 부터 18% 유리
- 120제 깡스탯 16: 614 이상 (약 122레벨) 부터 18% 유리
- 장비 스팩에 따라 18%가 유리해지는 시점은 130~145레벨까지 늦어짐

## V1.0 구현 방향

- 최대 스공만 산출 (최소 스공은 숙련도 미확보로 보류)
- 단검 부스탯은 유저가 STR/DEX 중 선택
- 마법사는 동일 공식 적용 (무기상수 1.0)

마법사 데미지 공식: `((마력² / 1000 + 마력) / 30 + INT / 200) × 스킬 공격력`
물뎀 직업 데미지 공식: `(무기상수 × 주스탯 + 부스탯) × 공격력 / 100`
