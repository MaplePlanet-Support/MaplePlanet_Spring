# 아이템 정밀 비교기 UX/UI 워크플로우

## Step 0. 비교 모드 선택

| 모드 | 용도 |
|------|------|
| 모드 1 - 단순 스탯 비교 | 방어구/장신구, 주스탯+% 비교 |
| 모드 2 - 정밀 스공 비교 | 공/마 포함 방어구 (공노목, 핑크가운 등) |
| 모드 3 - 무기 전용 비교 | 무기 교체 및 종류 변경 |

선택한 모드에 따라 이하 폼 입력칸 동적 변경.

---

## Step 1. 캐릭터 기초 정보

| 입력값 | 모드 1 | 모드 2 | 모드 3 |
|--------|--------|--------|--------|
| 직업 선택 (주/부스탯 라벨 자동 변경) | ✅ | ✅ | ✅ |
| 순수 주스탯 (직접 찍은 값) | ✅ | ✅ | ✅ |
| 순수 부스탯 (직접 찍은 값) | ❌ | ✅ | ✅ |
| 패시브 공/마 (정령의 축복, 여제의 축복 등) | ❌ | ✅ | ✅ |

---

## Step 2. 현재 장비 합산 스탯

**[💾 내 장비 불러오기 / 저장하기]** — 로컬스토리지 연동

### Tab A: 빠른 합산 (Quick)

| 입력값 | 모드 1 | 모드 2/3 |
|--------|--------|----------|
| 장비 깡 주스탯 합 | ✅ | ✅ |
| 주스탯 % 합 | ✅ | ✅ |
| 장비 깡 부스탯 합 | ❌ | ✅ |
| 무기 제외 공격력/마력 합 | ❌ | ✅ |

### Tab B: 부위별 상세 (Detail)

부위별 테이블 (모자, 상의, 하의, 장갑 ...).
각 행마다 깡스탯 / % / 공마 입력 → 하단 실시간 총합 자동 계산.

---

## Step 3. 교체 시뮬레이션 세팅

### 현재 장착 아이템 (영점 조절 — 빈칸이면 빈 슬롯으로 간주)

| 입력값 | 모드 1 | 모드 2 | 모드 3 |
|--------|--------|--------|--------|
| 깡 주스탯, 주스탯 % | ✅ | ✅ | ✅ |
| 깡 부스탯 | ❌ | ✅ | ✅ |
| 공/마 | ❌ | ✅ | ✅ |
| 무기 종류 드롭다운 | ❌ | ❌ | ✅ |

### 후보 아이템 A / B (현재 장착 아이템과 동일한 입력칸)

- 모드 3 전용: 보스 공격력, 크리티컬 확률 보조 옵션 추가 노출
- **[+ 후보 추가]** 버튼으로 C, D 확장 가능

---

## Step 4. 결과 대시보드 (Sticky 고정 or 우측 플로팅)

### 모드 1 — 단순 스탯
```
후보 A : 최종 스탯 1,700
후보 B : 최종 스탯 1,750
👑 추천: 후보 B가 주스탯 +50 더 높습니다!
```

### 모드 2 — 스공 정밀
```
후보 A : 최종 스탯 1,700 / 예상 스공 4,500
후보 B : 최종 스탯 1,690 / 예상 스공 4,620
👑 추천: 후보 B가 주스탯은 10 떨어지지만, 스공은 +120 더 높습니다!
```

### 모드 3 — 무기 비교
```
후보 A (두손검) : 예상 스공 4,500
후보 B (창)    : 예상 스공 4,800
👑 추천: 후보 B가 스공 +300 더 높습니다!
💡 보조 옵션 변동: [보스 공격력 +10%], [크리티컬 확률 -5%]
```
